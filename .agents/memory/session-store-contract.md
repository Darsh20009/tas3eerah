---
name: عقد الجلسات
description: الفرق غير الظاهر بين كائن express-session وشرط كائنات قاعدة البيانات العادية
---

**القاعدة:** قبل تمرير جلسة Express إلى واجهة تخزين تتطلب plain object، حوّل نسخة الجلسة إلى كائن JSON عادي عند حد SessionStore.

**Why:** express-session يمرر مثيل Session ذي prototype خاص. قد تعرض الصفحة العامة محتواها بينما يفشل حفظ رمز CSRF والجلسة ويصبح تسجيل الدخول مستحيلاً.

**How to apply:** عند تغيير تخزين الجلسات، اختبر طلب CSRF ثم تسجيل الدخول ثم فتح صفحة محمية بنفس ملف تعريف المتصفح، لا تكتفِ برمز استجابة الصفحة العامة.
