---
name: Integrated Classic Tools
description: قرار دمج أدوات القطاعات الأصلية داخل لوحة التحكم دون iframe
---

الأدوات الأصلية تُستخدم كمكوّن داخلي داخل لوحة التحكم، وليس كصفحة مستقلة أو iframe. يجب إبقاء منطق الحاسبات ومحتواها، مع عزل CSS داخل حاوية الأدوات وإعادة تسمية الدوال التي تتعارض مع دوال لوحة التحكم.

**Why:** الإطار المنفصل سبب اختلاف الهوية وصعّب التنقل والحفظ والصلاحيات، بينما الدمج الداخلي يجعل الحاسبات جزءاً من نفس صفحة النظام.

**How to apply:** عند تعديل الأدوات الأصلية، حافظ على partial الدمج الداخلي، وحدّث طبقة الربط التي تحول الحفظ المحلي إلى إنشاء عرض سعر عبر API بدلاً من إعادة إظهار iframe.
