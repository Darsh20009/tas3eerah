---
name: تخزين الإنتاج
description: سبب منع الرجوع التلقائي إلى SQLite عند تعذر MongoDB في الإنتاج
---

**القاعدة:** يجب إيقاف تشغيل الإنتاج بوضوح إذا تعذر الاتصال بـ MongoDB؛ لا تستخدم SQLite المحلية بديلاً تلقائياً ولا تنقل قاعدة البيانات الحالية دون طلب صريح.

**Why:** ملفات نظام الحاوية في Render مؤقتة. الرجوع الصامت إلى SQLite يجعل الحسابات والبيانات تبدو سليمة ثم تختفي بعد إعادة التشغيل أو إعادة النشر.

**How to apply:** عند تعديل التهيئة أو نظام التخزين أو إعداد النشر، أبقِ فشل MongoDB ظاهراً واحفظ بيانات التطوير القائمة دون حذفها.
