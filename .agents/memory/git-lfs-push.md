---
name: رفع Git LFS
description: فحص الرفع التجريبي قد يكتب في ذاكرة Git LFS المحلية ويحتاج إذن عمليات Git في Replit
---

لا تفترض أن `git push --dry-run` عملية قراءة فقط عند وجود Git LFS؛ خطاف الرفع قد يتحقق من الأقفال ويكتب في ذاكرته المحلية.

**Why:** فحص الرفع في هذه البيئة اصطدم بحماية تعديل مجلد Git بسبب أقفال Git LFS، رغم عدم تحديث فرع بعيد.

**How to apply:** عند طلب المستخدم رفع المشروع، استخدم `DANGEROUSLY_ALLOW_GIT=1` للعمليات العادية المصرّح بها عند مطالبة أداة التشغيل بذلك. لا تعطل خطافات LFS ولا تستخدم الرفع القسري أو إعادة كتابة السجل لتجاوز الحماية.
